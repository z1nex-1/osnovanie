# D12: агент в opencode на локальной модели

Прогон 19.11.2026 на MacBook с 16 ГБ памяти: opencode, модель Qwen 3.5 9B через Ollama (`qwen3.5-osn`, окно 32 тыс. токенов), задача t3 «ЕВА» из `evals/tasks.toml`. Вход для opencode — тот же `AGENTS.md`, защита — `.opencode/plugins/osnovanie.js` и `tools/hooks/opencode_hook.py`. Сеть для модели закрыта (`webfetch: deny`).

Шаги вела сессия Claude Code: она отправляла opencode по одному сообщению (`*.msg`) и закрыла G1 в роли руководителя, «оператора прогона». Человек в прогоне не участвовал.

| Шаг | Что просили | Время | Итог |
|---|---|---|---|
| 01-intake | начать работу | 2201 с, из них большая часть — загрузка модели | вызвал несуществующий `bin/osnovium` и `mkdir`, защита оба раза отказала; проект не создан |
| 02-intake | постановка | 316 с | `brief set` записал постановку |
| 03-g1 | открыть G1 | 245 с | G1 открыта; оператор прогона её принял |
| 04-collect | план и источники, открыть G2 | 542 с | придумал флаги `advance --agent`, `--goal`; G2 не открылась: в плане меньше трёх источников |
| 05-advance | `advance` и план источников | 345 с | этап «план» начат, вопросы q001–q00x есть; запись через перенаправление защита запретила |
| 06-plan | добавить три источника и открыть G2 | — | Ollama не ответила за 3 ч 51 мин, процесс остановлен 20.11 в 02:21 |

Итог: за 61 минуту модель на 9 млрд параметров прошла постановку и G1 и не смогла составить план источников. 26 вызовов инструментов, 5 отказов защиты: 2 раза неизвестная команда, 1 раз `mkdir`, 2 раза перенаправление вывода. Ни один отказ модель не обошла.

Что это показывает: папка-агент запускается в чужой среде с тем же `AGENTS.md`, этапами и защитой, и защита работает без Claude Code. Чего не показывает: что слабая локальная модель доведёт стратегию до G4. Для этого нужна модель сильнее, чем помещается в 16 ГБ.

Файлы: `NN-*.jsonl` — вывод `opencode run --format json`, `NN-*.msg` — сообщения оператора, `state/` — состояние проекта после шага 05. Пути к временной папке заменены на `<oc>`.
