# D13: агент против обычного чата

ТЗ просит измерить, насколько агент быстрее, дешевле или точнее обычного чата с ИИ и какой ценой. Здесь это измеряется на одних и тех же входных данных, и оценки ставятся вслепую.

## Как устроено сравнение

| | Агент | Обычный чат |
|---|---|---|
| Модель | Claude Opus 5.5 | Claude Opus 5.5 |
| Вопрос | из `evals/tasks.toml` | тот же |
| Материалы | источники, которые агент собрал и прочитал | те же тексты, склеенные в один запрос (`prepare --project`); карантин не входит |
| Требования к результату | навыки этапов | тот же список из `rubric.toml` прямо в запросе |
| Инструменты | `bin/osnovanie`, субагенты, хуки | никаких: один запрос без правок |
| Человек | отвечает в точках G1–G4, время учитывается | не участвует |

Чату дают те же требования, что и судьям. Если чат получит вопрос без требований, сравнение будет с заведомо слабым противником, и выигрыш агента ничего не скажет.

## Порядок

```bash
python3 evals/d13/d13.py prepare t1-meganeuroseti --project meganeuroseti
python3 evals/d13/d13.py chat t1-meganeuroseti
python3 evals/d13/d13.py agent t1-meganeuroseti --project meganeuroseti
python3 evals/d13/d13.py blind t1-meganeuroseti
python3 evals/d13/d13.py judge t1-meganeuroseti --judge sonnet
python3 evals/d13/d13.py judge t1-meganeuroseti --judge yandex
python3 evals/d13/d13.py score
```

- `blind` убирает признаки авторства. Внутренние номера утверждений агента превращаются в сноски с цитатой, так что судья видит, на что опирается вывод, но не видит, кто автор. Работы получают буквы X и Y в случайном порядке, ключ кладётся отдельно в `key.json`.
- `judge` показывает судье пару дважды: X перед Y, потом Y перед X. Если при смене порядка судья меняет предпочтение, в отчёте это помечено как «неустойчив к порядку», и такое предпочтение не считается.
- `human.toml` — та же рубрика для оценки человеком. Ключ открывается только после оценки.
- `score` собирает `report.md` и `results.json`: баллы по рубрике, цену в рублях, время человека, долю чисел, которые находятся в материалах, и пункты, где агент проиграл.

## Ограничения

- Сверка чисел механическая: число из фразы ищется в тексте материалов. Совпадение короткого числа может быть случайным. Расчёт, которого нет в материалах, попадает в «не найдено» и проверяется вручную по списку `untraced`.
- Судья sonnet из того же семейства, что и обе работы. Поэтому нужен судья другого семейства — YandexGPT, ключ `YANDEX_API_KEY` и `YANDEX_FOLDER_ID`. Вызов YandexGPT написан по документации и ещё не проверен на настоящем ключе.
- Материалы для судьи обрезаются до 60 тысяч знаков.
- Время чата — это время одного ответа модели. Время человека, который читает и дорабатывает ответ чата, не измерено и в отчёте стоит отдельной строкой.
