# Время, расходы и ограничения заявленных возможностей

Замеры 18.11.2026 на MacBook (Apple Silicon), Python 3.15. Время — `time -p`, реальное. Где число получено оценкой, это сказано в строке.

## Заявленные возможности

| Возможность | Статус | Доказательство |
|---|---|---|
| Точки G1–G4 и R закрывает только сообщение человека | есть | хук `tools/hooks/claude_hook.py`, тесты `tests/test_path.py`, `tests/test_security.py`, `make eval` |
| Каждое число стратегии ведёт к дословной цитате | есть | `bin/osnovanie check`, `verify`; 15 из 15 дефектов блокируют G4 (`evals/report.md`) |
| Пересказ не искажает цитату: число, оговорка, допущение как факт | есть, механически | `bin/osnovanie fidelity`, `tests/test_fidelity.py`; смысловые искажения без чисел и оговорок не ловит |
| Скрытый текст страниц не доходит до модели | есть | 0 из 48 атак слепого корпуса (`evals/report.md`) |
| Детектор инъекций | частично | 19 из 48 атак при 7 ложных из 40; это первый слой, защищают хуки и карантин |
| Пересмотр «что упало и почему» | есть | `review`, отчёт `projects/meganeuroseti-ref/outputs/review-1.md`: 4 вывода упали, 47 из 51 устояли |
| Лучше обычного чата | частично | D13 (`evals/d13/report.md`): Sonnet и Qwen согласны — агент выигрывает у чата без поиска, чату с поиском и с теми же материалами проигрывает; см. ниже |
| Работа в Cursor и Codex | не проверено | файлы `.cursor/`, `.codex/` есть, прогона нет |
| Живой прогон на новой задаче | нет | шесть задач `evals/tasks.toml` не прогнаны, нужен вход в Claude Code |
| Вторая модельная семья | частично | судьи YandexGPT-Lite и Qwen в D13; сам агент на другой модели не прогонялся |

## Что D13 говорит честно

Агентская рука в D13 — эталонный проект, а не живой прогон. Руки чата — свежие субагенты без доступа к репозиторию. После первого раунда судьи мы дважды правили эталон по его замечаниям, а чат второго шанса не получал. Поэтому честное сравнение — раунд 1, и в нём агент уступает чату с поиском и с материалами. Раунды 2 и 3 показывают, что замечания судьи исправимы, но не то, что агент лучше. Подробности — `evals/d13/report.md` и `evals/d13/README.md`.
