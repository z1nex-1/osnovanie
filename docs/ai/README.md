# Как ИИ работал в этом проекте

Здесь две разные вещи, и их легко смешать.

1. **ИИ внутри агента.** «Основание» — это папка с инструкциями, навыками, субагентами и инструментом `bin/osnovanie`. Модель читает инструкции, выбирает следующий шаг, вызывает инструменты и проверяет результат. Ключевые промпты собраны в [PROMPTS.md](PROMPTS.md), модели и сервисы перечислены ниже.
2. **ИИ при сборке агента.** Код, методики и тексты писались в Claude Code (Claude Opus 5.5) под руководством автора. Автор решал, что строить и в каком порядке, принимал или отклонял изменения, сам фиксировал правила (`rules lock`). Ошибки ИИ при сборке и как они были пойманы — в [MISTAKES.md](MISTAKES.md).

## Модели, сервисы и инструменты

| Что | Для чего | Обязательно |
|---|---|---|
| Claude Code | среда, в которой живёт агент: чат, навыки, хуки, субагенты, MCP | да, или Cursor / Codex через `AGENTS.md` |
| Claude Opus 5.5 | основной агент: ведёт этапы, пишет варианты и стратегии | по подписке Claude Code |
| Claude Sonnet 5.5 | субагенты skeptic, closure-advocate, verifier, researcher; запасной судья | там же |
| Claude Haiku 5.5 | source-sanitizer (единственный, кто читает текст источников), synthetic-respondent, судья по умолчанию без Jev | там же |
| Jev (typesafe.ai) | узкий классификатор для маршрутизации и коротких оценок «да/нет», «выбери из списка» | нет, `TYPESAFE_API_KEY`; без него судья — haiku, потом sonnet |
| WebSearch Claude Code | поиск открытых источников субагентом researcher; страницы скачивает `source fetch` из списка разрешённых доменов | нет, источники можно положить файлами |
| Python 3.11+, стандартная библиотека | `bin/osnovanie`: утверждения, проверки, модель вариантов, стоимость, реплей | да |
| uv | запуск тестов и evals | только для `make test` |

Маршрут по сложности задачи и откат судьи заданы в `config/thresholds.toml`, цены моделей с датой сверки — в `config/prices.toml`. Каждый вызов модели пишется в журнал проекта с ценой, поэтому `bin/osnovanie cost` показывает полную стоимость результата вместе с временем человека.

## Чего здесь нет

Полные журналы сессий сборки не выкладываются: в них личные настройки автора, не относящиеся к агенту. Работу самого агента показывает реплей демо-прогона (`bin/osnovanie replay build`), из которого вырезаны ключи, пути, почты, телефоны и скрытые рассуждения модели; если что-то похожее на секрет остаётся, файл не пишется.
