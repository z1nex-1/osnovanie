# Ошибки ИИ при сборке и как их поймали

Агент собирался в Claude Code. Ниже ошибки, которые ИИ сделал при сборке и которые были пойманы. Для каждой указано, чем поймали и что изменили, чтобы она не повторилась. Опечатки, которые сразу ловил запуск, сюда не входят. Исключение — две, по которым видно, какие проверки работают.

Детектор понижен до первого слоя. ## Что из этого следует для агента

Ошибки 1, 3 и 5 одного типа: результат выглядит правильным, а мерили не то. Против них в агенте те же приёмы:

- **Отложенная проверка.** Вывод проверяют на материале, которого не видели при работе над ним. В стратегии эту роль играет субагент verifier: он сверяет цитаты заново и не видит, как писались утверждения.
- **Число берётся из одного места.** В стратегии оно берётся из утверждения `[c012]`, в документах — из `docs/facts.json`.
- **Тихий откат виден в журнале.** Каждый вызов судьи пишет модель и цену. Если вызов откатился, это видно в `bin/osnovanie cost`.
