# Разбор интерфейса

1. Загрузи снимок: `bin/osnovanie source add screen.png --kind own`. OCR положит текст в материалы.
2. Открой изображение и найди проблемы по эвристикам H1–H10 (`methods/ux-heuristics.md`). Называй только то, что видно.
3. Запиши JSON: `[{"source_id":"s009","heuristic":"H5","severity":"высокая","finding":"что не так","bbox":[x,y,w,h]}]` и `bin/osnovanie ux add --file ...`. Координаты в пикселях. Если рамка выходит за изображение, команда отклонит находку.
4. Находка остаётся гипотезой, пока её не подтвердили данные о поведении. Карта доверия покажет рамки поверх снимка.
