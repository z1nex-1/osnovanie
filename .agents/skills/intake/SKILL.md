# Постановка

1. Прочитай запрос. Если проекта нет: `bin/osnovanie new <имя> --question "..." --title "..."`.
2. Определи, что уже известно: вопрос, цель, получатель, ограничения, доступные данные.
3. Спроси только то, без чего следующий шаг пойдёт не туда. Не больше трёх вопросов за раз. Остальное запиши как допущение и покажи.
4. Запиши: `bin/osnovanie brief set --question "..." --goal "..." --recipient "..." --constraints "..." --data "..."`.
5. Открой точку: `bin/osnovanie gate open G1 --summary "как я понял задачу, в двух предложениях"`. Покажи человеку вывод и остановись.
6. После `G1 да`: `bin/osnovanie advance`. После правки исправь постановку и открой точку снова.
