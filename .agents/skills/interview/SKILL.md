# Интервью

Реальные интервью проводит человек. Ты готовишь гайд по `methods/jtbd.md`: прошлое поведение вместо мнений о будущем, без наводящих вопросов.

Загрузка расшифровки: `bin/osnovanie interview add файл --consent "номер записи согласия"`. Команда блокирует файлы с персональными данными. Анализ идёт как с любым источником.

Модельные респонденты: вызывай субагента `synthetic-respondent` с разными ролями, минимум три, включая скептика и равнодушного. Запиши гипотезы типом `synthetic`. Они подсказывают, что спросить у людей, и никогда не обосновывают спрос: `check` отклонит абзац о спросе, опирающийся только на них.
