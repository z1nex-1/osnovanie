# Анализ отзывов

Основано на тематическом анализе (V. Braun, V. Clarke, «Using thematic analysis in psychology», 2006).

## Когда применять

Голос пользователя из открытых отзывов: магазины приложений, отзовики, форумы.

## Процедура

1. Выборка: площадка, период, версия приложения, число отзывов, способ отбора. Без этого вывод невоспроизводим.
2. Таблица с полями дата, оценка, текст, версия → `bin/osnovanie source add reviews.csv --kind reviews`, затем `bin/osnovanie data profile`.
3. Темы: прочитай первые 20% отзывов, выдели 5–9 тем с правилами отнесения (ключевые слова). Запиши правила.
4. Подсчёт тем через `bin/osnovanie data calc` с `contains`, по периодам и оценкам. Расчёт становится утверждением `calculation`.
5. Цитаты-примеры — утверждения `opinion` с источником.

## Перекосы, которые надо назвать

Отзывы пишут чаще недовольные и восторженные; отзывы после обновления концентрируются во времени; часть отзывов накручена; площадка сама отбирает показанные отзывы. Доля темы в отзывах не равна доле проблемы среди пользователей.
