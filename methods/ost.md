# Дерево возможностей (Opportunity Solution Tree)

Автор: Тереза Торрес.

Цель сверху, ниже возможности (потребности и боли), ниже решения, ниже проверки. Одно решение привязано к одной возможности.

Использование: варианты проекта строятся от разных возможностей, тогда они действительно разные. Два решения для одной возможности — это варианты исполнения, не стратегии.
