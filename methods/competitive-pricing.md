# Ценовая лестница конкурентов

## Когда применять

Варианты с изменением цены, бандла, тарифа; коммуникация ценности против альтернатив.

## Процедура

1. Для каждой альтернативы — тариф со страницы цен как факт с цитатой и датой проверки. Цены меняются: дата обязательна.
2. Приведи к общей единице: рублей в месяц за сопоставимый объём (запросов, пользователей, генераций). Правило пересчёта — расчёт через `bin/osnovanie data calc` или модель.
3. Отметь неценовые различия: лимиты, модели, способ оплаты, доступность без VPN, хранение данных.
4. Лестница: бесплатный уровень → входной платный → основной → для команд. Найди пустые ступени и ступени, где мы дороже без отличия.
5. Изменение цены у конкурента — типичный повод для пересмотра решения: свяжи цены с выводами через `depends_on`.

## Типовые ошибки

Сравнение номинала без объёма; цены без даты; акционная цена подана как постоянная.
