# Оценка порядка величины

Источник: метод оценок Э. Ферми; D. Hubbard, «How to Measure Anything», 2014 (калиброванные интервалы).

## Когда применять

Размер рынка, охват, нагрузка, если прямых данных нет.

## Процедура

1. Разложи величину на множители, которые можно найти или правдоподобно ограничить: число компаний × доля с нужной работой × доля, готовая платить онлайн × частота.
2. Для каждого множителя — источник или интервал low–high, в который ты уверен на 90%.
3. Считай через `bin/osnovanie model`: диапазон честнее точки.
4. Сверь с независимым якорем другим путём (сверху вниз и снизу вверх). Расхождение больше чем в 3 раза — повод искать ошибку, а не усреднять.

## Типовые ошибки

Точный ответ с тремя значащими цифрами; множители, которые дважды учитывают одно и то же; нет второго пути проверки.
