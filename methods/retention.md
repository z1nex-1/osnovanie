# Анализ удержания

Источники: A. Chen, «The Cold Start Problem», 2021 (кривые удержания); общепринятый когортный анализ.

## Когда применять

Вопросы «почему падает удержание», «почему не возвращаются».

## Процедура

1. Определи, что значит «удержан»: событие ценности и окно (день 1, 7, 30). Без определения вопрос не решается.
2. Если есть данные пользователя: когорты по месяцу первого действия, кривая удержания по каждой. Хорошая кривая выходит на плато; падение без плато — продукт не стал привычкой.
3. Раздели проблему: не активировались (не получили первую ценность) или активировались и ушли (ценность не повторяется, нашли замену, изменилась цена).
4. Без внутренних данных (открытые источники): только косвенные сигналы — темы отзывов по периодам, изменение рейтинга после версий, изменения тарифов и условий, действия конкурентов. Вывод о причине — гипотеза, разобранная по `methods/ach.md`.
5. Проверь скучные объяснения: изменение подсчёта, сезонность, смена канала привлечения (новые когорты хуже).

## Готово, если

Определение удержания есть, гипотезы о причинах разобраны таблицей конкурирующих гипотез, а план проверки называет данные, которые отделят причины друг от друга.
