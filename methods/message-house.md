# Дом сообщений

Распространённый инструмент коммуникационной практики.

Крыша: одно ключевое сообщение для одной аудитории. Стены: 3 опоры. Фундамент: доказательства каждой опоры, связанные с утверждениями и возможностями продукта. Если у опоры нет доказательства, её убирают или переводят в обещание с датой.
