# Каркасы метрик AARRR и HEART

Источники: D. McClure, «Startup Metrics for Pirates», 2007; K. Rodden, H. Hutchinson, X. Fu, «Measuring the User Experience on a Large Scale», Google, CHI 2010.

## Когда применять

Исследование («на каком шаге теряем») и план проверки.

## AARRR

Привлечение → активация (первая ценность) → удержание → выручка → рекомендации. Для каждого шага: определение события, источник данных, базовое значение или «неизвестно».

## HEART

Удовлетворённость, вовлечённость, принятие, удержание, успех задачи. Для каждой выбранной категории: цель → сигнал → метрика. Не все категории нужны: выбирай под решение.

## Правила

- Открытые данные почти никогда не дают внутренних метрик. Тогда метрика описывается, базовое значение помечается «неизвестно, измеряется в пилоте».
- Рейтинг в магазине приложений — сигнал удовлетворённости с перекосом (пишут недовольные и восторженные), не замена удержания.
