# Основание

Папка-агент для руководителя цифрового продукта. Открываете её в Claude Code или Cursor, пишете вопрос своими словами («кому продавать», «почему уходят», «что сказать клиентам») — агент ведёт работу от постановки до продуктовой и коммуникационной стратегии с планом проверки. Каждое число в стратегии ведёт к дословной цитате источника, у каждого варианта есть сильное возражение, а когда приходят новые данные, агент сам находит выводы, которые на них держались.

В цифрах на 18.11.2026: скрытый текст страниц не дошёл до агента ни в одной из 48 атак слепого корпуса, 15 из 15 дефектов стратегии блокируют утверждение, пересказ сверяется с цитатами без модели, а в слепом сравнении с обычным чатом агент выигрывает у чата без поиска и пока проигрывает чату с поиском и с теми же материалами — все прогоны и проигрыши лежат в репозитории.

Работа для номинации «ИИ-проект» MGIMO AI Challenge 2026 (задача МегаФона «Стратег Фабрики продуктов»). Материалы неофициальные, используются только открытые данные.

## Проверить за три минуты, без ключей

Нужны Python 3.11+ и [uv](https://docs.astral.sh/uv/) (для тестов).

```bash
make doctor   # окружение, хуки, навыки, хеши правил
make test     # 83 теста: путь от запроса до решения, точки человека, защита, верность пересказа
make eval     # оценки: инъекции, каналы атак, дефекты стратегии → evals/report.md
bin/osnovanie --project meganeuroseti-ref fidelity   # пересказ против цитат, 0,2 с
```

Время каждой команды, цена прогонов и что из заявленного проверено, а что нет, — `docs/LIMITS.md`.

Что показывает `make eval` на 14.11.2026 (`evals/report.md`):

- скрытый текст страниц (display:none, комментарии, alt) не дошёл до агента ни в одной из 48 атак нового слепого корпуса;
- после всех атак точка человека G1 осталась открытой, проверенных фактов — 0;
- 15 из 15 формальных дефектов стратегии (число без ссылки, обещание без возможности, спрос только из модельных респондентов, нет базы сравнения и т. д.) блокируют утверждение;
- детектор инъекций на регулярных выражениях на новом корпусе ловит 19 из 48 атак при 7 ложных срабатываниях из 40. Это первый слой, а не защита; почему — в `evals/HISTORY.md`.

## Полный прогон

1. Установите [Claude Code](https://docs.claude.com/en/docs/claude-code) и войдите (подписка или ключ API).
2. Откройте папку и напишите задачу в чате. Первое, что сделает агент, — `bin/osnovanie resume`.
3. Отвечайте в точках G1–G4: что писать — в `docs/MANAGER.md`.

Ключи не обязательны. `TYPESAFE_API_KEY` подключает узкий классификатор Jev для маршрутизации; без него судья откатывается на haiku, затем sonnet, и это видно в журнале. Шаблон — `.env.example`.

## Новое

- `fidelity` сверяет пересказ без модели: числа утверждения должны быть в цитате, оговорка цитаты («около», «планирует», «по оценке») не теряется, а допущение или прогноз в абзаце стратегии названы так прямо. Последнее — ошибка, она блокирует G4.
- Пересмотр показывает, что упало и почему: цепочку «вывод → на чём держался», параметры модели было/стало и сколько выводов устояло. На эталоне новый факт про Билайн задел 4 вывода, 47 из 51 устояли, лидер не сменился (`projects/meganeuroseti-ref/outputs/review-1.md`).
- D13, слепое сравнение с обычным чатом (`evals/d13/report.md`): три руки чата, судьи Sonnet, YandexGPT-5-Lite и Qwen через Ollama, обе очерёдности, у каждой оценки дословная цитата. Раунд 1 — честный: агент сильнее чата без поиска, слабее чата с поиском и с материалами. Раунды 2–3 сделаны после правок агента по замечаниям судьи и подписаны как подгонка.
- `bin/osnovanie demo seed` собирает эталонный проект `meganeuroseti-ref` из 27 проверенных цитат (`demo/meganeuroseti-sources.md`): настоящими функциями движка, без сети и без агента. Точки закрыты каналом `demo-seed`; формулировки вариантов и допущений авторские.
- `whatif` показывает, что упадёт, если убрать источник или утверждение, и когда меняется лидер модели; ничего не записывает.
- `watch [--apply]` перескачивает разрешённые страницы и ищет исчезнувшие цитаты.
- `deck` собирает `outputs/deck.html`: 14 слайдов, у каждого числа сноска на цитату.
- `score [--badge файл.svg]` считает индекс обоснованности по формуле из `docs/score.md`.
- `export site --out DIR` пишет пакет `project.json` схемы `osnovanie-site/1` (`docs/site-schema.md`) с раскладкой графа.

## Как устроено

| Слой | Где |
|---|---|
| Постоянные правила | `AGENTS.md` (вход для любой среды), `instructions/quality.md` |
| Этапы и навыки | `.agents/skills/` → intake, collect, research, options, strategy, validation, review, interview, ux-review, data-analysis |
| Методики | `methods/` — 21 файл с процедурой, типичными ошибками и критерием готовности (JTBD, Rumelt, COM-B, ACH, Fermi, unit-экономика, A/B с расчётом MDE…) |
| Инструмент | `bin/osnovanie` — 44 команды: утверждения, источники, проверки, модель вариантов, точки человека, пересмотр, стоимость, реплей прогона, эталонный проект (`demo seed`), `whatif`, сторож `watch`, презентация `deck`, индекс `score`, пакет сайта `export site`, верность пересказа `fidelity` |
| Защита | хуки `tools/hooks/claude_hook.py`: запись только в `outputs/`, точки закрывает только человек, карантин инъекций, бюджет |
| Субагенты | `.claude/agents/`: skeptic, closure-advocate, verifier, researcher, source-sanitizer, synthetic-respondent |
| Знания между проектами | `kb/`, поиск `search`, MCP `kb-state` |
| Эталонный проект | `demo/` → `demo seed` → `projects/meganeuroseti-ref/`; `deck`, `score`, `whatif`, `watch`, `export site` работают на любом проекте |
| Состояние проекта | `projects/<проект>/state/` — журналы на диске, поэтому работа продолжается в новом чате |

Требования ТЗ по пунктам и команды проверки — `docs/CRITERIA.md`. Модели, ключевые промпты и ошибки ИИ при сборке — `docs/ai/`.

## Как встраивается в контур компании

- Те же команды, что у агента, доступны людям и системам: `bin/osnovanie` с `--json` встраивается в трекер, дашборд и CI без переписывания. MCP-сервер `kb-state` и HTTP только для чтения отдают состояние проекта другим инструментам.
- Регламент нельзя тихо поменять: хеши правил лежат в `config/rules.lock.json`, расхождение видно в `doctor` и роняет проверку. Зафиксировать новые правила может только человек в терминале.
- Службе безопасности не надо верить на слово: `make eval` за пару минут повторяет замер по инъекциям на слепом корпусе.
- Точки G1–G4 и R закрываются только сообщением человека — хук не даёт агенту ответить за руководителя.

## Ограничения

- Живого прогона агента на открытых данных МегаФона нет: на 18.11 вход в Claude Code на машине сборки просрочен. Эталонный проект собран движком из 27 цитат, ответы в точках дала демо-команда. Цены и времени полного прохода поэтому нет (`docs/LIMITS.md`).
- В D13 агентская рука — этот эталон, а не живой прогон; честный результат — раунд 1, и в нём агент уступает чату с поиском и с теми же материалами.
- `fidelity` ловит числа, оговорки и допущения, поданные как факт. Смысловое искажение без чисел и оговорок механикой не ловится.
- Переносимость в Cursor и Codex подготовлена (`.cursor/`, `.codex/`, `export`/`import`), но в этих средах не проверена. Прогон агента на шести новых задачах (`evals/tasks.toml`) не сделан.
- Агент не ходит в закрытые данные и не пишет никому от вашего имени.
