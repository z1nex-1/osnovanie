# План и источники

1. Сформулируй вопросы, ответ на которые может изменить решение. На каждый: что именно изменится. `bin/osnovanie question add "..." --changes "..."`. Вопросы из любопытства не записывай.
2. Поручи субагенту `researcher` найти источники и записать план. Нужны первичные источники, отраслевые и голос пользователей.
3. Назначь бюджет: `bin/osnovanie budget set <usd>`.
4. Открой G2 и остановись: `bin/osnovanie gate open G2 --summary "..."`.
5. После `G2 да`: `bin/osnovanie advance`.
