# План проверки

`outputs/validation.md`, разделы: Ожидаемое изменение, С чем сравниваем, Срок наблюдения, Нежелательные последствия.

- Метрика решения по `methods/north-star.md`, входные метрики по `methods/metrics-aarrr-heart.md`.
- Базовое значение со ссылкой или пометкой «неизвестно, измеряется в пилоте».
- Ожидаемый сдвиг — прогноз, назван прогнозом, с MDE из экономики.
- Сравнение: контрольная группа, период до или квазиэксперимент (`methods/ab-test.md`), размер выборки расчётом.
- Срок наблюдения в днях или неделях, не меньше недельного цикла, и порог остановки.
- Нежелательные последствия: две-три антиметрики с порогами.
- Главный риск по `methods/cagan.md` проверяется первым и самым дешёвым тестом.

После `G4 да`: запиши обязательства, по одному на решение: `bin/osnovanie commit add --file ...` с полями `what, owner, due (ГГГГ-ММ-ДД), check_at, metric, threshold, expected, review_if, claims`. `expected` — какой итог ожидаем к `check_at` (дата первой проверки, по умолчанию `due`): это ставка, с которой потом сверяется факт. В `review_if` — сигналы из пре-мортема и утверждения, от которых решение зависит сильнее всего.
